Append one CSV row durably (flush + fsync).

localbenchmark.localbenchmark.build_program(code, row)

Build the file to execute.

The prompt is placed first (with a stub body) so that imports and helper functions from the prompt exist, then the model’s code redefines the entry point. If the model returned only a function body, it is attached to the prompt’s signature instead.

localbenchmark.localbenchmark.create_summary(results_file)
localbenchmark.localbenchmark.determine_model_contexts(base_url, model, requested)

Clamp requested contexts to the model’s maximum (max tested once).

localbenchmark.localbenchmark.execute_program(program, timeout=10)

Runs generated code in a throw-away temp dir. NOTE: this is not a real sandbox. Use Docker for untrusted models.

localbenchmark.localbenchmark.experiment_id_for(model, context_requested, cache_label, fill)

Deterministic ID that can be computed BEFORE loading the model, so a finished configuration can be skipped without a slow model load.

localbenchmark.localbenchmark.extract_code(response)
localbenchmark.localbenchmark.get_actual_context(load_response)
localbenchmark.localbenchmark.get_corpus(min_chars)

Unrelated Python source (the stdlib) used as realistic filler.

localbenchmark.localbenchmark.get_gpu_memory()

Sum memory over ALL GPUs. Returns (used_mb, total_mb) or (None, None).

localbenchmark.localbenchmark.get_lm_models(base_url)
localbenchmark.localbenchmark.load_completed(results_file)

Set of (experiment_id, problem_id) that are DONE. Rows that failed with LLM_ERROR (server crash, timeout, …) are NOT considered done, so they are retried on the next run.

localbenchmark.localbenchmark.load_humaneval()
localbenchmark.localbenchmark.load_model(base_url, model, context, extra_params)
localbenchmark.localbenchmark.load_probe_done(probe_file)
localbenchmark.localbenchmark.load_summary_configs(results_file)

Set of (model, cache_label, context_requested, fill_ratio) present in the summary CSV. A configuration missing from the summary is treated as not finished: the entire experiment for that config will be re-run even if some individual problem rows exist in the detailed results file.

Token levels that fit safely into this context window.

localbenchmark.localbenchmark.repair_results_file(results_file)

If a previous run was killed while writing a row, the CSV can end with a torn record (no trailing newline) or fail to parse. Back the file up and rewrite it without the damaged record so appending/resuming is safe.

localbenchmark.localbenchmark.run_experiment(df, meta, args, results_file, force_rerun=False)
localbenchmark.localbenchmark.run_plots(results_file, plots_dir, probe_file=None, diag_file=None)
localbenchmark.localbenchmark.run_probe(meta, args, probe_file)

For each token level: fill the KV cache with N tokens of unrelated code, then generate a short fixed-format answer and time it. Filler differs per repetition, so LM Studio’s prefix cache can’t hide the prefill cost.

Note

Core evaluation entry points are also available as modules:

  • localbenchmark.llm_coding_benchmark — HumanEval / speed-probe CLI

  • localbenchmark.plot_results — ranking and trend plots

  • localbenchmark.analyze_slowdown — context vs speed analysis
