Scoring for non-coding test suites (countries, politics, people, companies, world events).

No LLM judge. Answers are scored with normalized, fuzzy and negation-aware matching. Every score comes with a detail dict, so each result can be audited.

Item types

mc multiple choice: a letter, “(B) text”, “answer is B”, or the option text numeric a number within a relative or absolute tolerance, with partial credit short a short fact: any accepted answer; distractors halve the score if also named keywords weighted concept groups, each with aliases; partial credit per group rubric open answer: reserved for a judge model, not scored here unanswerable company QA: the documents do not contain the answer; the model must say so

Company documents for QA suites.

Put every document in one folder (default: company_docs/). Files are used in name order, so –limit 40 uses the first 40. Use –ids to choose exact files. Suite items name the documents that contain their answer in “context”, using file names relative to the folder.

Token counts are estimates (words x 1.35). The real count is the prompt_tokens value in the results after a run.

python docs.py estimate company_docs/ # size and window fit python docs.py estimate company_docs/ –limit 40

Plots for llm_coding_benchmark.py results.

Standalone:

python plot_results.py –results coding_benchmark_results.csv –out plots

Also called automatically at the end of the benchmark (disable with –no-plots). If the CSV contains several –fill ratios, one sub-folder is written per ratio, because runs with different fill are not comparable with each other.

Average metric scores across context windows per model, then rank.

Context capability = max planned context size completed, with fixed ranks (180k→1 … 50k→5, <35k→6). Models with NaN decode speed or TTFT go to the bottom.

localbenchmark.llm_plots.rank_sum_table(agg, rank_agg='sum')

Rank each (series, context) on five metrics and combine the ranks.

Rank 1 = best. Lower combined score is better overall.

Metrics (direction):

pass_rate_adj higher better — aborted runs: unrun problems count as fail tps higher better ttft lower better gpu_mb lower better context higher better — larger context size is better

rank_agg: “sum” | “mean” | “median” — how ranks are combined.

Rows with NaN decode speed or TTFT are excluded from ranking and placed at the bottom.

  • –results <name>_summary.csv: its per-problem sibling <name>.csv.

Note

The package modules are:

  • localbenchmark.localbenchmark: the localbenchmark command (benchmarks, suites, dry run)

  • localbenchmark.suite_scoring: suite loading, question types and scoring

  • localbenchmark.docs: the document folder for company QA

  • localbenchmark.llm_plots: the localbenchmarkplot command
