Installation

Python 3.10+ is required. Recommended is to install localbenchmark in an isolated environment using conda or venv.

Create Conda Environment

conda create -n env_localbenchmark python=3.12
conda activate env_localbenchmark
pip install localbenchmark

Create venv Environment

# Create a new project directory
mkdir my_localbenchmark_project
cd my_localbenchmark_project

# Create virtual environment
python -m venv venv

# Activate it
# On macOS/Linux:
source venv/bin/activate

# On Windows:
venv\Scripts\activate

# Install localbenchmark
pip install localbenchmark

Pypi

# Install from PyPI:
pip install localbenchmark

# Force update to latest version
pip install -U localbenchmark

Github Source

# Install directly from GitHub
pip install git+https://github.com/erdogant/localbenchmark

From source (development)

git clone https://github.com/erdogant/localbenchmark
cd localbenchmark
pip install -r requirements.txt
pip install -e .

LM Studio

The coding benchmark and speed probe expect a running LM Studio server (default http://localhost:1234) with models available on the machine.

  1. Install LM Studio

  2. Download one or more coding models

  3. Enable the local server (Developer mode)

  4. Note the model key (as shown in LM Studio) for --models

Dependencies

Core packages: numpy, pandas, matplotlib, requests, tqdm, openai, scikit-learn, pymupdf, json_repair, datazets.

Optional: llama-cpp-python if you load local GGUF files through LLMlight helpers instead of LM Studio.

Uninstalling

Remove environment

# List all the active environments. env_localbenchmark should be listed.
conda env list

# Remove the environment
conda env remove --name env_localbenchmark

# List all the active environments. env_localbenchmark should be absent.
conda env list

Remove installation

pip uninstall localbenchmark
